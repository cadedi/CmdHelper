---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability or security bug in this project, please **DO NOT** open a public GitHub issue.

Please report security concerns responsibly by creating a private Security Advisory on GitHub or contacting the maintainers. We appreciate your efforts in responsibly disclosing vulnerabilities.

---

## 🛡️ Data Privacy & Air-Gapped Environments

- **Zero Telemetry**: CmdHelper collects **no telemetry**, tracking, or analytics data.
- **Air-Gapped Ready**: Both the standalone binaries and the exported single-file HTML have **zero external CDN dependencies** and are safe for deployment on air-gapped, confidential, or high-security networks.
